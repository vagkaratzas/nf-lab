A Nextflow plugin · prototype

Follow a plate from Nextflow to the robot, and back.

nf-lab puts robotic wet-lab steps in Nextflow pipelines, with no change to the language. A wet step never runs twice, an aborted run stops a robot safely, and every plate's provenance lands in Nextflow lineage. Press Next, or click any station, to send plate Q01 down the line.

What's real on this page
  • Computed here, as nf-lab computes it: plate Q01's map (from examples/qpcr/plate_map.csv), its idempotency key (SHA-256, as labctl builds it) and each well's Ct (as the simulated qPCR instrument gives it).
  • Simulated, like nf-lab's own demos: the robots. nf-lab runs against PyLabRobot's simulated machines; no robot is needed.
  • Illustrative: timings (a qPCR run takes about 1.5 hours, here a few seconds), task hashes, job IDs and the other plates in the pool.

Run it yourself

Everything above runs on your machine against simulated robots. You need Java 17, uv and Nextflow 26.10.0 or later.

git clone https://github.com/vagkaratzas/nf-lab && cd nf-lab
make install          # builds the plugin into ~/.nextflow/plugins
cd dashboard && uv run uvicorn nf_lab_dashboard.app:main --factory --port 8080

Open http://127.0.0.1:8080 and pick a demo: qpcr runs this page's pipeline, 1000 samples over ten simulated robots, while a narrator plays the person at the bench. plate_transfer → E-stop shows the abort, the safe stop and a -resume that runs only the stopped plate again.
