# Security policy

nf-labrobotics is a prototype. It drives simulated machines, and only the latest release gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead: on the repository's **Security** tab, choose **Report a vulnerability**. Include what you found, how to reproduce it, and which release you used.

Issues that let a pipeline or a network caller make a machine move when it shouldn't, such as bypassing the run ledger or the safe-stop boundary, count as security issues even on simulated machines.
